# Scripts

This folder contains auxiliary scripts that do not belong to either the `tests` or `experiments` directories. These scripts were developed for specific purposes and have been retained because they may be useful for future development, validation, or reproducibility.

The current scripts include:

1. A grid search utility for parameter exploration and optimization.
2. Two validation scripts that compare the new implementation against the previous one, ensuring that outputs and behavior remain consistent across versions.

These scripts are not part of the regular test suite but serve as valuable tools for development and verification.
