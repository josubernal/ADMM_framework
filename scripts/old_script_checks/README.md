# ADMM-SNN Testing Framework: Validation & Comparison

This directory contains two test scripts designed to validate our new ADMM-based optimization framework against the old version. These tests ensure algorithmic correctness and numerical stability by systematically comparing our framework against the baseline code proposed in:

> **ADMM-Based Training for Spiking Neural Networks** > Giovanni Perin, Cesare Bidini, Riccardo Mazzieri, and Michele Rossi (2025)

## Overview of Test Scripts

### 1. Original Multiblock Implementation
We compare our multiblock version against the original code.

### 2. Modified Two-Block Implementation
We modify the original version slightly to match our two-block version and compare.

Note: For both test scripts original version's small bugs have been corrected.
