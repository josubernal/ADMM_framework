# Tests

This folder contains unit and integration tests for the different components of the module. Each test is documented in its corresponding file and is intended to verify the correct behavior of a specific part of the codebase.

Tests should be self-contained and executable without requiring external data or resources. Additional tests are encouraged as the project evolves to improve coverage and reliability.

To run all tests from the root directory of the repository, execute:

```bash
python -m pytest -s tests/
```
